# Design Standards, Inspiration & Animation Rules

## Reference Hubs (Permanent)
- **Gym UI Benchmarks**: [Dribbble Gym UI](https://dribbble.com/tags/gym-ui)
- **Visual Design & Aesthetics**: [Pinterest UI Inspiration](https://in.pinterest.com/)
- **Micro-Animations & UI Elements**: [Jitter Video UI Templates](https://jitter.video/templates/ui-elements/)
- **Vector Icons**: [Flaticon](https://www.flaticon.com/)

## Design Mandate
- Always draw inspiration from these hubs for modern, cutting-edge fitness web & mobile application layouts.
- Use polished micro-animations (entry transitions, badge pulses, smooth modal reveals).
- Ensure premium SaaS visual aesthetics: clean typography, refined gradients, no raw emojis in interactive controls.
