# UI Icon Standards

- **Official Icon Source**: [Flaticon](https://www.flaticon.com/)
- **Rule**:
  1. Do NOT use raw Unicode emojis (like 👁️, 🎟️, 📅, 📱, etc.) in UI controls, action buttons, cards, or table actions.
  2. For all icons, use clean SVG vector icons sourced/styled from Flaticon.
  3. Keep all reusable SVG icon components organized in `fitcore-web/src/components/common/Icons.jsx` and asset folders.
